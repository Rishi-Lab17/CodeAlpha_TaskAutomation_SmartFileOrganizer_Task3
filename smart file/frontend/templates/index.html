Project Overview

The Smart File Organizer is an enterprise-grade automation suite designed to streamline routine file management, information extraction, and web content scraping. Designed with a strict safety-first philosophy, every operation guarantees data integrity, atomic file moves, duplicate conflict resolution, and persistent audit logs.

Non-destructive Moves Automatic Renaming Strict JPG Scope Regex Parsing HTTP Scraping

Automation Architecture

  • os
    Filesystem Inspection: Validates read/write permissions, verifies paths, and scans directory entries.
  • pathlib
    Path Mathematics: Resolves absolute paths, inspects case-insensitive extensions, and generates unique collision-free names.
  • shutil
    Safe File Movement: Executes non-destructive atomic transfers via shutil.move() without overwriting.
  • re
    Regular Expressions: Sanitizes, matches, and extracts valid email addresses from text files up to 20 MB.
  • requests
    HTTP Streaming: Safely fetches webpage HTML streams with timeout controls and custom User-Agent headers.
  • Flask
    REST API: Asynchronous worker threads with live polling for multi-file operations.
